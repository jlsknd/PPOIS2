#  TV Manager - Система управления телевизором

## Описание проекта

**TV Manager** - это программная система для моделирования работы современного телевизора с пультом дистанционного управления. Проект реализован в двух вариантах интерфейса:

- **CLI (Command Line Interface)** - консольное приложение для управления телевизором через командную строку
- **Web (Flask)** - веб-приложение с современным адаптивным интерфейсом

Оба интерфейса используют **единый общий код** (модели, сервисы, репозиторий), что демонстрирует принцип повторного использования кода и разделения ответственности.

---

## Цель работы

Разработать веб-интерфейс к программной системе, полученной в лабораторной работе №1, с использованием фреймворка Flask, сохранив общий код для CLI и веб-версий.

## Архитектура

### Принципы проектирования

| Принцип | Реализация |
|---------|------------|
| **Single Responsibility** | Каждый класс имеет одну ответственность: `Screen` - экран, `AudioSystem` - звук, `Television` - ТВ |
| **Open/Closed** | Классы открыты для расширения, закрыты для модификации |
| **Liskov Substitution** | Использование Enum для ограничения значений |
| **Interface Segregation** | Интерфейсы классов не перегружены |
| **Dependency Inversion** | Зависимости от абстракций через импорты |
| **DRY** | Общий код вынесен в `src/`, используется и CLI, и Web |
| **KISS** | Простые и понятные решения без усложнений |

## Функциональные возможности

### Основные возможности

| Категория | Функции |
|-----------|---------|
| **Управление питанием** | Включение/выключение телевизора |
| **Режимы** | Кабельное ТВ, Smart TV |
| **Каналы** | Переключение вверх/вниз, прямой ввод номера, список каналов |
| **Громкость** | Пошаговое изменение (+5/-5), прямой ввод, Mute |
| **Изображение** | Яркость (0-100), контраст (0-100) |
| **Звук** | Эквалайзер (НЧ, СЧ, ВЧ от -100 до 100), подключение сабвуфера |
| **Сеть** | Wi-Fi (вкл/выкл), Bluetooth (вкл/выкл) |
| **Bluetooth** | Поиск устройств, сопряжение, подключение/отключение |
| **HDMI** | Подключение/отключение устройств по портам |
| **Smart TV** | Обновление ПО (по одной версии или все до лимита) |
| **Управление ТВ** | Добавление, удаление, выбор текущего телевизора |
