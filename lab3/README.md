# Jewel Quest - Match-3 Game

Игра в жанре **Match-3**, разработанная на **Python** с использованием библиотеки **Pygame**.  
Учебный проект в рамках лабораторной работы по объектно-ориентированному программированию.



## Возможности

-  Два режима игры: **на время** и **на очки**
-  Три уровня сложности в режиме на очки
-  Специальные кристаллы: бомбы, очистители рядов и столбцов
-  Комбинации спецкристаллов для мощных эффектов
-  Плавные анимации с функциями плавности (easing)
-  Фоновая музыка и звуковые эффекты
-  Система паузы
-  Таблица рекордов с сохранением в JSON
-  Внешняя конфигурация через `config.json`
-  Красивое анимированное меню

## Архитектура

Проект построен по **модульному принципу** с использованием **событийно-ориентированного программирования**:

- **Конечный автомат состояний** (`GameState`) управляет экранами игры
- Все игровые объекты разделены на независимые классы
- Конфигурация вынесена во внешний JSON-файл
- Звуки загружаются динамически при наличии файлов

### Диаграмма состояний игры

```
MENU → MODE_SELECT →  LEVEL_SELECT → PLAYING
                    ↘           \
                     TIME MODE   |
                      ↓          ↓
                   PLAYING    PAUSED ⇄ PLAYING
                      ↓           ↓
                  GAME_OVER    MENU
                      ↓
                 INPUT_NAME → LEADERBOARD
```

## Игровые механики

### Обычные кристаллы
6 цветов кристаллов. Совпадение **3+ в ряд** (горизонтально или вертикально) приводит к их удалению и начислению очков(35).

### Специальные кристаллы

| Кристалл | Условие создания | Эффект |
|----------|------------------|--------|
| **Бомба** | 5+ в ряд | Взрыв области **3х3** при обмене с любым соседним кристаллом |
| **Удаление ряда** | 4 в ряд горизонтально | Удаляет **весь горизонтальный ряд**. Активируется в ряду с 2+ кристаллами своего цвета |
| **Удаление столбца** | 4 в ряд вертикально | Удаляет **весь вертикальный столбец**. Активируется в ряду с 2+ кристаллами своего цвета |

### Комбинации спецкристаллов
- **Бомба + Удаление ряда** = удаление **3 рядов** (текущий ±1)
- **Бомба + Удаление столбца** = удаление **3 столбцов** (текущий ±1)
- **Область взрыва бомбы + Удаление ряда/столбца** = взрыв области **3х3** и удаление **задетого ряда/столбца**
- **Удаление ряда + удаление столбца** = удаление **креста**

### Система комбо
При цепных реакциях (когда после удаления и падения новых кристаллов снова образуются совпадения) активируется **множитель комбо**, увеличивающий очки.

### Отсутствие ходов
Если на доске не осталось возможных ходов — игра заканчивается сообщением **"Ходов нет!"**, грустным смайликом и звуком "не получилось, не фортануло".

## Режимы игры

### Режим на время (60 секунд)
- Игра в течение **60 секунд**
- При **15 секундах** включается напряжённая музыка
- Бомбы падают с неба (шанс 3%)
- **Рекорды сохраняются** в таблицу

### Режим на очки (3 уровня)

| Уровень | Особенности | Цель |
|---------|-------------|------|
| **Уровень 1** (Лёгкий) | Все утилиты | **3000** очков |
| **Уровень 2** (Средний) | Без бомб, только удаления ряда | **3500** очков |
| **Уровень 3** (Сложный) | Без утилит | **5000** очков |

## Система анимаций

В игре реализованы плавные анимации с использованием **функций плавности (easing)**:

### Типы анимаций

| Анимация | Функция плавности | Описание |
|----------|-------------------|----------|
| **Появление кристаллов** | `ease_out_bounce` | Кристаллы "выпрыгивают" при создании |
| **Обмен кристаллов** | `ease_out_cubic` | Плавное перемещение при обмене |
| **Падение кристаллов** | `ease_in_out_quad` | Ускорение и замедление при гравитации |
| **Удаление кристаллов** | `ease_out_cubic` | Уменьшение масштаба до нуля |
| **Пульсация заголовка** | `sin` | Ритмичное изменение размера |
| **Свечение кристаллов** | `sin` | Мерцание альфа-канала |
| **Звёздочки в меню** | Гравитация + вращение | Подъём с затуханием |
| **Падающие кристаллы (меню)** | Линейное + вращение | Декоративный фон |

### Функции плавности (Easing)
- `ease_out_cubic` — быстрое начало, плавное завершение
- `ease_in_out_quad` — ускорение посередине
- `ease_out_bounce` — эффект отскока

## Конфигурация

Файл `config.json` содержит все настройки игры:

```json
{
  "display": {
    "width": 900,        // Ширина окна
    "height": 700,       // Высота окна
    "fps": 60,           // Кадры в секунду
    "title": "Jewel Quest"
  },
  "grid": {
    "rows": 8,           // Количество строк
    "cols": 8,           // Количество столбцов
    "cell_size": 60,     // Размер ячейки в пикселях
    "offset_x": 150,     // Смещение сетки по X
    "offset_y": 80,      // Смещение сетки по Y
    "gem_types": 6       // Количество типов кристаллов
  },
  "modes": {
    "time": {
      "duration": 60,         // Длительность режима (сек)
      "tense_threshold": 15   // Порог для напряжённой музыки
    },
    "points": {
      "levels": [3000, 3500, 5000]  // Цели по уровням
    }
  }
}
```

## Таблица рекордов

- Хранится в файле `leaderboard.json`
- Топ-**10** результатов
- Отдельное окно режима **на время** 
- Отдельное окно режима **на очки** 
- При новом рекорде появляется окно ввода имени
- Результаты сортируются по убыванию очков

## Использованные технологии

- **Python 3.14**
- **Pygame 2.6.1** (SDL 2.32.10)
- **JSON** для конфигурации и хранения данных
- **Enum** для состояний игры и типов кристаллов
- **Easing-функции** для плавных анимаций
